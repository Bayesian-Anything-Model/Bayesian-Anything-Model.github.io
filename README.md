# bayesian-anything-model.github.io

Project page for *BAM! Bayesian Anything Model: a foundation model for generative computational imaging*,
built on the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).

`index.html` is generated by `tools/build_page.py` from `tools/index.template.html` and the paper's Overleaf
sources (paths at the top of the script): it extracts the Figure 1 tiles, the comparison images and the CT
panels, converts the flow-map and Pareto plots to SVG, and turns the LaTeX tables into HTML.

```sh
pip install pymupdf pillow
python tools/build_page.py
```

Small edits can also be made directly in `index.html`, but they are overwritten by the next build.
